Yes, start tonight. It doesn’t matter that the laptop isn’t yours, because Railway deploys from GitHub, not from a laptop. You push your code to GitHub, and Railway builds and hosts it. So whichever machine you code on, the app ends up in the same place.

On a borrowed laptop:

One Railway thing to get right: your SQLite database needs a Railway Volume. Listing the Railway setup steps
Listing the Railway setup steps

Yes, there’s a real chance. If the app already runs on your computer and the code is on GitHub, getting it live on Railway usually takes under an hour:

  1. Create a new Railway project from your GitHub repo.
  2. Add a volume and mount it at /data.
  3. Point your SQLite file to /data with a variable like DB_PATH=/data/royale.db.
  4. Generate a public domain so the guys can open the app.

After that, it stays live on its own as long as your Railway plan covers it, and every push to GitHub updates it automatically.

And yes, the points math is fully defined, so you can code it as written:

  • Win: 3 points
  • Game played: 1 point
  • Court time: 1 point per hour, counted only during live games
  • Reset: every 30 days
  • Levels: In the Mix 20+, Contender 35+, Playoff Bound 50+, Best Record in the League 55+
  • King of a park: most points earned at that park, with court time as the tiebreaker
